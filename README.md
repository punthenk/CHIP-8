# CHIP-8
This is a working implementation of the CHIP-8 Emulator I wrote myself in C++.

---
## Compiling and run the emulator
**Requirements:**
- SDL2
- CMake v3.16 or higher

To build:
```bash
mkdir build
cd build
cmake ..
make
```

There are 23 roms in the roms directory that you can try. I downloaded them [here](https://www.zophar.net/pdroms/chip8.html).
